# Code of Conduct

## Our Commitment

We want Raw-Gent to be a welcoming, respectful project for contributors of different backgrounds, experience levels, and perspectives.

Participation in this project should be collaborative, constructive, and safe for everyone.

## Expected Behavior

Examples of behavior that help build a healthy community:

- being respectful and patient in discussions
- giving feedback that is specific, kind, and technically useful
- assuming good intent while still being honest about problems
- being open to different viewpoints and approaches
- taking responsibility for mistakes and correcting them
- focusing on what is best for the project and its users

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment, discrimination, or intimidation
- insults, personal attacks, or inflammatory language
- trolling, deliberate disruption, or bad-faith engagement
- publishing other people's private information without permission
- sexualized language or imagery in project spaces
- repeated hostility after being asked to stop

## Scope

This Code of Conduct applies in project spaces, including:

- GitHub issues
- pull requests
- code review comments
- discussions tied to the repository
- maintainer and contributor interactions related to project work

## Reporting

If you experience or witness unacceptable behavior, report it privately to `arpanmondal572@gmail.com`.

Please include as much context as you can, such as:

- what happened
- where it happened
- who was involved
- links, screenshots, or logs if available

## Enforcement

Project maintainers may take any action they believe is appropriate to protect the community, including:

- requesting a change in behavior
- removing comments or content
- closing or locking discussions
- rejecting contributions
- temporarily or permanently banning a participant from project spaces

## Enforcement Principles

Enforcement will aim to be:

- fair
- proportionate
- respectful of reporters
- focused on protecting the community
